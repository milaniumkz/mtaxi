# MTaxi 1.3.2 (69): проверка поездок

Изменения исходников:
- Ручное «На месте» доступно назначенному водителю без GPS. Автоматическое прибытие и старт требуют точных последовательных GPS-точек и подтверждения присутствия у подачи.
- Отбрасываются неточные, устаревшие, перепутанные по времени и скачущие координаты; сохраняется последняя достоверная точка.
- Ручное изменение адреса сбрасывает его координаты и расчёт; устаревший ответ маршрута не меняет актуальные точки. Выбранный адрес не подменяется обратным геокодированием.
- Геокодирование с заданным населённым пунктом не возвращает одноимённую улицу другого города. Отсутствующий адрес требует уточнения на карте, а не подстановки вымышленных координат.
- При смене заказа сбрасываются навигация и голосовые подсказки; результат предыдущего заказа игнорируется. Сервер проверяет соответствие концов и длины маршрута выбранным точкам.
- Все предложения пассажиру отображаются компактным списком сверху. Водитель принимает цену либо отправляет одну из трёх пропорциональных надбавок сразу.
- Повторное принятие предложения не отправляется; переход водителя к принятому заказу защищён от повторной навигации.
- Стабильная подписка пассажира на текущий заказ не пересоздаётся при каждом обновлении экрана.
- Чат доступен только назначенным участникам в статусах 2/3/4. Сервер закрывает доступ после поездки, проверяет участника, ограничивает частоту и устраняет дубликаты отправки.
- При одобрении водителя сервер создаёт адресное уведомление; повторное одобрение его не дублирует.
- На iOS собственный MessagingDelegate больше не подменяет обработчик Firebase Messaging; FCM-токены не печатаются в native-лог.
- В пополнении автоматически установлен +7.

## Управление без обновления приложения

В админке → Настройки сервиса доступны бонусы, комиссия, межгород, а также новые серверные параметры:

| Поле | Значение по умолчанию | Допустимо |
|---|---:|---:|
| autoArrivalRadiusM | 60 м | 20–120 |
| autoArrivalDelaySec | 15 сек | 5–120 |
| autoDepartureRadiusM | 100 м | 80–500 |
| autoStartDelaySec | 15 сек | 5–120 |
| driverOfferLifetimeSec | 30 сек | 15–120 |

Фактический радиус автостарта всегда минимум на 20 м больше радиуса прибытия. Срок предложения возвращается сервером в expiresAt. Цены, бонусы, комиссия, права, денежные операции, геокодирование и маршрутизация выполняются существующими серверными API. Новые серверные API добавляются совместимо: выпущенный клиент не должен зависеть от развёртывания следующей версии.

Изменение интерфейса, разрешений ОС, нативной регистрации push и SDK требует новой подписанной версии. Серверные настройки не загружают исполняемый код и не обходят проверку магазинов.

## Push: границы проверки

Работа Android подтверждена владельцем. Это не подтверждает APNs или Web Push. Workflow `MTaxi push diagnostics (read only)` выводит только агрегированные регистрации и результаты доставки по платформам, наличие Web VAPID secret; ничего не отправляет, не печатает банковские данные, токены или персональные данные.

Для iOS нужны Apple APNs authentication key в Firebase Cloud Messaging, правильные Team ID / Key ID / Bundle ID com.milanium.mtaxi, GoogleService-Info.plist проекта mtaxi-52990 и подписанная сборка с Push Notifications. Ключ .p8 не коммитить и не помещать в приложение.
Владелец передал публичный Web Push VAPID key 17 ноября; он сохранён в config/firebase_web_public.json (это публичная конфигурация). Сборщик использует его при отсутствии GitHub Actions secret FIREBASE_WEB_VAPID_KEY. После пересборки веба необходимо разрешение уведомлений на отдельном домене админки. Разрешение пассажирского домена не распространяется на домен админки. Приватный VAPID-ключ не нужен клиенту.
Фактическое получение на iPhone и в браузере подтверждается отдельно на устройствах, а не HTTP-ответом FCM.

APK/AAB/IPA этой задачей не собираются. M Business не затрагивается. Локальная проверка: flutter analyze — без замечаний; Flutter — 148 тестов успешно; Node — 219 успешно, 3 пропущены (проверки PostgreSQL требуют отдельной тестовой БД). Включены серии по 20 повторов/конкурентных запросов для маршрутов, GPS и чата. Физические iPhone/Android в этой среде не проверялись. Результат деплоя фиксируется отдельно после завершения workflow.
