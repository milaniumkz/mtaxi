# Проверка приложения (ручной чек-лист)

Ниже список ручных проверок, чтобы самостоятельно убедиться, что всё работает.
Рекомендуется пройти последовательно.

## 1) Регистрация и вход
1. Установить приложение, открыть.
2. Зарегистрироваться новым номером (пассажир).
3. Пройти заполнение профиля (посёлок/город, имя).
4. Перезапустить приложение — данные должны сохраниться.

## 2) Пассажир: оформление заказа (такси)
1. Открыть главный экран.
2. Проверить, что поле "Откуда" подтянуто автоматически (геолокация).
3. Ввести "Куда" вручную — появляются подсказки по выбранному посёлку.
4. Не выбирая подсказку, нажать "Заказать" — заказ должен создаваться и виден водителю.
5. После выбора подсказки — маршрут строится, цена рассчитывается.
6. Проверить комментарий (виден, текст не сливается с фоном).

## 3) Пассажир: доставка
1. Переключить тип на "Доставка".
2. Заполнить "Что доставить".
3. Проверить цену (с учётом доставки).
4. Заказ создаётся и доступен водителям.

## 4) Пассажир: межгород (на одной странице)
1. Переключить на "Межгород".
2. Выбрать "Откуда" и "Куда".
3. Проверить маршрут на карте и цену (из админки).
4. Заказ создаётся и доступен водителям с пометкой "МЕЖГОРОД".

## 5) Поиск водителя
1. После оформления — экран поиска водителя без карты (как задано).
2. При назначении водителя — карта с маршрутом и статусом.
3. При отмене/истечении 20 минут — заказ удаляется, возвращает на оформление.

## 6) Водитель: лента заказов
1. Войти как водитель (роль approved).
2. В ленте видны заказы в радиусе 20 км или по совпадению города (если нет координат).
3. Межгород помечен бейджем "МЕЖГОРОД".
4. Принять заказ — статус обновляется, список очищается.

## 7) Поддержка (чат)
1. Пассажир: Настройки → Служба поддержки → отправить сообщение.
2. Админ: Админка → Чат поддержки → ответить.
3. Проверить уведомления о новых сообщениях.

## 8) Админка
1. Открыть админку под админ-логином.
2. В разделе "Заказы" создать запись:
   - Тип: Такси / Доставка / Межгород
   - Поселок, Откуда, Куда, Цена
3. Проверить, что заказ появляется у водителя.

## 9) Политика и условия
1. Открыть "Политика" — текст виден, фон белый.
2. Проверить "Служба поддержки" — текст виден.

## 10) Иконка приложения
1. Убедиться, что иконка не дефолтная (Flutter), а из логотипа.
